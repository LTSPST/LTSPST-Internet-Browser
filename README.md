# LTSPST Internet Browser

## Описание
*Браузер создан для защиты пользователей от слежки и проект разрабатывается на телефоне без ПК
## Главные функции
* **Сохранение истории:** сохранение истории можно отключать и включать (по умолчанию эта функция отключена)
* **Есть блокировка рекламы:** реклама блокируется, ничего не мешает загрузке страниц (эта функция пока в обработке)

## Системные требования
* **OC:** Android
* **Версия:** 8.0 Oreo - 16 Baklava
